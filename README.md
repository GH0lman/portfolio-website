# Portfolio Website

A personal portfolio built with `Next.js`, showcasing my projects, 
skills, and experience as a graduating software developer.

**Live site:** [georgeholman.dev](https://georgeholman.dev) *(To Be Implemented and Hosted)*

## About

Built to present my work to recruiters and hiring managers as I finish up my Bachelor of Computing Systems degree in New Zealand. The goal is a fast, clean site that lets the projects speak for themselves and streamline contact with me directly.


## Tech Stack

- **Framework:** Next.js v16.2.6 (App Router)
- **Styling:** Tailwind CSS v4.3.0
- **Language:** TypeScript
- **Deployment:** Vercel

## Prerequisites
- Node.js 20+
- pnpm (`npm install -g pnpm`)

## Getting Started

```bash
git clone https://github.com/GH0lman/portfolio-website.git
cd portfolio-website
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.


## Project Structure
```bash
app/         > pages and routing
components/  > reusable UI components
public/      > static assets
```
